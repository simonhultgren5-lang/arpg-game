# Models

Game-ready models go here. See [../README.md](../README.md) for formats and naming. Originals belong in `/source-assets/Models/`.

`characters/` and `props/` are built by the Blender scripts in `scripts/assets/blender/` (`bun run assets:build`). Each model is a `.gltf` with its `.bin`, and its textures come from `../textures/materials/`. Don't edit these by hand; change the script and rebuild. See [assets.md](../../../assets.md).
