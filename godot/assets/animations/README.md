# Animations

Game-ready animations go here. See [../README.md](../README.md) for formats and naming. Originals belong in `/source-assets/Animations/`.

The characters' animation clips (idle, walk, attack, cast, hit, death) are inside their models in `../models/characters/`, so this folder is for shared clips only. See [assets.md](../../../assets.md#6-animation).
